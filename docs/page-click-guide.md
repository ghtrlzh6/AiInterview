# 页面点击体验指南

本文档说明在前端页面中按什么顺序点击，才能完整体验 AI 模拟面试平台的主要功能。推荐先走普通用户流程，再用管理员账号体验后台配置与管理功能。

## 一、体验前准备

1. 启动后端、前端和数据库。
   - 后端默认地址：`http://localhost:8080`
   - 前端默认地址：`http://localhost:5173`
   - 前端会把 `/api` 请求代理到后端。

2. 打开浏览器访问 `http://localhost:5173`。

3. 如果没有登录，会自动进入登录页。
   - 普通演示账号：输入用户名 `demo_student`，密码 `demo123456`，点击「登录」。
   - 管理员账号：输入用户名 `admin`，密码 `admin123456`，点击「登录」。
   - 也可以点击「立即注册」，填写用户名、昵称、邮箱、密码后点击「注册并登录」。

## 二、普通用户完整点击顺序

### 1. 首页总览

1. 登录后进入「首页」。
2. 查看顶部欢迎区、累计面试次数、最近面试得分。
3. 点击首页的「评估报告」卡片，可进入历史报告列表；看完后点击左侧「首页」返回。
4. 点击首页的「成长曲线」卡片，可进入能力趋势页；看完后点击左侧「首页」返回。
5. 点击首页的「知识库」卡片，可进入知识阅读页；看完后点击左侧「首页」返回。
6. 在首页「最近面试」表格中：
   - 如果有「继续面试」，点击后可恢复未完成面试。
   - 如果有「查看报告」，点击后可进入报告详情。
   - 如果有「生成报告」，点击后会进入报告生成页。
7. 点击「所有面试」，进入完整面试历史列表，稍后也可以从左侧菜单「所有面试」进入。

### 2. 完善个人档案和简历

1. 点击左侧菜单「个人档案」。
2. 在「头像」区域点击「更换头像」，选择 JPG、PNG、WEBP 或 GIF 图片。
3. 填写或修改「昵称」「学校」「专业」「教育经历」「个人能力」「项目经历」「实习 / 工作经历」。
4. 在「目标岗位」下拉框中选择一个岗位方向。
5. 点击「保存修改」。
6. 在「PDF 简历」区域，将 PDF 简历拖入上传框，或点击上传框选择 PDF。
7. 等待页面显示「解析成功」。
8. 查看「识别到的项目经历」和「解析全文预览」。

说明：简历解析成功后，开始面试页面可以选择使用该简历，面试中会出现项目深挖相关问题。

### 3. 创建一场模拟面试

1. 点击左侧菜单「开始面试」，或在首页点击「开始模拟面试」。
2. 在「输入方式」中选择「文字」或「语音」。
3. 调整「题目数量」滑块，建议演示时选择 3 到 5 题，节省时间。
4. 在「简历项目深挖」区域：
   - 如果已经上传并解析过简历，可以选择「使用个人档案简历」。
   - 如果不想使用简历，选择「不使用简历」。
   - 如果需要临时简历，点击「临时上传 PDF 简历」，等待解析完成。
5. 在岗位卡片中点击一个岗位，例如 Java 后端、Web 前端、Python 算法或游戏客户端。
6. 点击页面底部「进入面试间」。

### 4. 面试间对话

1. 进入面试间后，先查看顶部的岗位名、会话编号、题号和连接状态。
2. 阅读当前题目卡片中的题型、主题和题干。
3. 如果输入方式是文字：
   - 在底部输入框输入回答。
   - 点击「发送（Ctrl+Enter）」或按 `Ctrl+Enter`。
4. 如果输入方式是语音：
   - 使用语音输入组件完成录音和转写。
   - 转写文本会进入回答输入框。
   - 确认后点击「发送（Ctrl+Enter）」。
5. 等待 AI 面试官流式回复。
6. 如果面试官追问，继续在输入框回答并点击「发送（Ctrl+Enter）」。
7. 当系统进入下一题时，继续重复回答。
8. 如果题型变为「手撕代码」，右侧会出现代码提交区：
   - 在语言下拉框选择 Java、TypeScript、Python、C++ 或 C#。
   - 在代码输入框填写代码。
   - 点击「提交代码」。
   - 查看代码提交反馈。
   - 再在左侧回答框补充解题思路和复杂度，点击「发送（Ctrl+Enter）」。
9. 完成题目后，或需要提前结束时，点击右上角「结束面试」。
10. 在确认弹窗中：
    - 点击「结束并生成报告」，进入报告生成页。
    - 点击「暂不生成」，返回首页，之后可在首页或「所有面试」中点击「生成报告」。

### 5. 报告生成页

1. 如果已经选择生成报告，页面会显示「面试已结束」和报告生成进度。
2. 等待按钮从「报告生成中...」变为「查看完整报告」。
3. 点击「查看完整报告」进入报告详情。
4. 如果之前选择暂不生成报告：
   - 进入面试结束页后点击「现在生成报告」。
   - 或返回首页，在最近面试记录中点击「生成报告」。

### 6. 查看报告详情

1. 在报告详情页查看岗位名称、综合得分和报告状态。
2. 查看「能力雷达图」。
3. 查看「亮点」「待改进」「综合评估」「逐题点评」「改进建议」。
4. 点击右上角「分享报告」，系统会复制分享链接。
5. 在「推荐学习资源」区域：
   - 点击「打开链接」访问资源。
   - 点击「有帮助」或「没帮助」提交反馈。

### 7. 评估报告列表

1. 点击左侧菜单「评估报告」。
2. 查看所有历史报告列表。
3. 点击某条报告的「查看」，进入报告详情页。
4. 回到左侧菜单继续体验其他模块。

### 8. 所有面试

1. 点击左侧菜单「所有面试」。
2. 查看每场面试的岗位、状态、报告、时长、开始时间和结束时间。
3. 根据记录状态点击：
   - 「继续面试」恢复进行中的面试。
   - 「查看报告」打开已有报告。
   - 「生成报告」为已完成但未生成报告的面试生成报告。
4. 点击右上角「开始面试」可重新进入岗位选择页。

### 9. 成长曲线

1. 点击左侧菜单「成长曲线」。
2. 在岗位下拉框选择「全部岗位」或某一个岗位。
3. 在时间范围下拉框选择「近 30 天」「近 90 天」或「近 180 天」。
4. 点击「刷新」。
5. 查看综合分变化、最强维度、最弱维度和折线图。

说明：成长数据来自已生成的报告，至少完成并生成一份报告后才会有曲线。

### 10. 知识库阅读

1. 点击左侧菜单「知识库」。
2. 在左侧「知识目录」中点击一个目录节点。
3. 如果节点下有文章按钮，点击文章标题按钮。
4. 在右侧阅读 Markdown 正文。
5. 继续点击其他目录节点和文章，体验知识库树形阅读。

### 11. 学习资源

1. 点击左侧菜单「学习资源」。
2. 如果是从报告详情跳转，并带有 `reportId`，页面顶部会显示「基于报告的推荐」。
3. 在推荐资源中点击「打开链接」。
4. 点击「有帮助」或「没帮助」提交反馈。
5. 在「资源搜索」中输入主题关键词。
6. 点击「搜索」。
7. 在搜索结果表格中点击「打开」访问资源链接。

### 12. 退出登录

1. 点击页面右上角「退出」。
2. 系统回到登录页。

## 三、管理员后台点击顺序

管理员流程建议使用 `admin / admin123456` 登录。登录后如果左侧出现「管理后台」，说明当前账号有管理员权限。

### 1. 进入后台仪表盘

1. 点击左侧菜单「管理后台」。
2. 默认进入「仪表盘」。
3. 查看总用户、总面试、总报告、今日面试、7 日活跃等统计卡片。

### 2. 岗位管理

1. 点击后台左侧「岗位管理」。
2. 查看岗位列表。
3. 点击「新增岗位」。
4. 填写「编码」「名称」「描述」。
5. 点击「保存」。
6. 在列表中点击「编辑」，修改名称或描述后点击「保存」。
7. 如果是测试数据，可点击「删除」，在确认框中确认删除。

建议：演示删除功能时使用刚新增的测试岗位，避免删除内置岗位。

### 3. 题库管理

1. 点击后台左侧「题库管理」。
2. 在「岗位编码」输入框输入岗位编码，点击「查询」。
3. 点击「新增题目」。
4. 填写「岗位编码」「题型」「难度」「题干」。
5. 点击「保存」。
6. 在题目列表中点击「编辑」，修改题目后点击「保存」。
7. 点击「AI 生成题目」。
8. 填写「岗位」「知识模块ID」「数量」。
9. 点击「生成」。
10. 如果是测试题目，可点击「删除」并确认。

### 4. 知识库管理

1. 点击后台左侧「知识库」。
2. 查看左侧知识节点树。
3. 点击「新增」创建知识节点。
4. 填写「标题」，选择「分组」或「知识点」，必要时填写父节点 ID。
5. 点击「保存」。
6. 在左侧树中点击某个节点。
7. 点击右侧「新增正文」。
8. 在「Markdown 正文」输入框中填写内容。
9. 点击「保存正文」。
10. 点击「向量化」触发当前正文向量化。
11. 点击「批量向量化」触发待处理正文批量向量化。

### 5. AI 配置

1. 点击后台左侧「AI 配置」。
2. 查看 AI 服务配置项。
3. 如需修改，填写 API Key、模型或其他配置。
4. 点击「保存配置」。
5. 点击「测试连通性」。
6. 查看页面上方的测试结果提示，包括模型和延迟。

说明：敏感配置如果已经存在，会以掩码显示；不修改时保持输入框为空即可。

### 6. 用户管理

1. 点击后台左侧「用户管理」。
2. 在「搜索用户名」输入框中输入关键词。
3. 点击「搜索」。
4. 查看用户 ID、用户名、昵称、角色和面试次数。
5. 在操作列的角色下拉框中选择 `USER` 或 `ADMIN`。
6. 页面提示「角色已更新」后，列表会刷新。

建议：不要随意修改当前登录管理员自己的角色，避免失去后台访问权限。

### 7. 学习资源管理

1. 点击后台左侧「学习资源」。
2. 在岗位下拉框选择岗位，点击「查询」。
3. 点击「新增资源」。
4. 填写「岗位」「标题」「描述」「类型」「链接」「主题」「难度」「质量分」。
5. 点击「保存」。
6. 在列表中点击「编辑」，修改资源后点击「保存」。
7. 如需清理测试数据，点击「删除」并确认。

### 8. 返回前台

1. 点击后台左侧底部「返回前台」。
2. 回到普通用户前台页面。

## 四、最快完整验收路径

如果只想快速体验全部核心功能，可以按下面顺序点击：

1. 登录 `demo_student / demo123456`。
2. 「个人档案」 -> 上传 PDF 简历 -> 等待解析成功 -> 「保存修改」。
3. 「开始面试」 -> 选择输入方式 -> 调整题目数量为 3 -> 选择岗位 -> 「进入面试间」。
4. 在面试间回答问题 -> 「发送（Ctrl+Enter）」。
5. 遇到手撕代码题时，选择语言 -> 填写代码 -> 「提交代码」 -> 再发送文字说明。
6. 点击「结束面试」 -> 「结束并生成报告」。
7. 等待报告完成 -> 「查看完整报告」。
8. 报告详情页 -> 查看雷达图、逐题点评、建议 -> 「分享报告」 -> 推荐资源中点击「有帮助」。
9. 左侧「成长曲线」 -> 选择岗位和时间 -> 「刷新」。
10. 左侧「知识库」 -> 点击目录节点 -> 点击文章标题。
11. 左侧「学习资源」 -> 输入关键词 -> 「搜索」 -> 点击「打开」。
12. 左侧「所有面试」 -> 查看历史 -> 点击「查看报告」或「生成报告」。
13. 退出后登录 `admin / admin123456`。
14. 「管理后台」 -> 依次点击「岗位管理」「题库管理」「知识库」「AI 配置」「用户管理」「学习资源」。

## 五、注意事项

1. 如果存在未完成面试，系统会自动跳转到面试间，需要先继续或结束当前面试，才能访问其他前台页面。
2. 没有配置真实 LLM API Key 时，系统仍可使用内置模拟回复和启发式评分完成演示。
3. 报告生成、简历解析和向量化是异步过程，页面可能需要等待数秒。
4. 删除、修改角色、修改 AI 配置等后台操作会影响真实数据，演示时优先使用测试数据。
